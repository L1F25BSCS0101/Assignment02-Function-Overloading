## Problems
- `p1_mobile_bill.cpp`: Calculates mobile bills using default arguments and prints separator lines.
- `p2_student_info.cpp`: Demonstrates function overloading for student information.
- `p3_array_tools.cpp`: Implements overloaded array sum, count, and print functions with default arguments.
- `p4_ride_fare.cpp`: Calculates ride fares using overloaded functions and writes receipts to `rides.txt`.

## Compile
Compile each file independently with a C++ compiler, for example:

```bash
g++ -std=c++17 p1_mobile_bill.cpp -o p1
g++ -std=c++17 p2_student_info.cpp -o p2
g++ -std=c++17 p3_array_tools.cpp -o p3
g++ -std=c++17 p4_ride_fare.cpp -o p4
```

Run each compiled program separately. The ride program creates `rides.txt` in its current working directory.
